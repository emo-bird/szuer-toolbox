# 手测清单 —— UOOC 视频助手（U1 二倍速 / U2 静音）

> **被测对象**：`dist/szuer-toolbox.user.js`（v0.1.0，构建号 **#48**）
> **被测分支**：`feat/uooc-ai`（提交 `405926f`，基于 `aacf9f3`）
> **执行方式**：装进 Tampermonkey → 逐条跑 → 逐条打勾
> **回话格式**：全过回「OK」；某条不过回「第 N 条：<现象>」+ Console 报错全文 + 截图
> **时间紧时**：先跑 **#156 / #157 / #158 / #161** 这 4 条（最关键的）

## 0. 这一轮改了什么（先读这段，知道该盯什么）

- 新写了 UOOC 的二倍速与静音两个功能 ↦ 视频播起来应当是 **2.0 倍速 + 静音**。
- 关掉开关时**只回退脚本自己改的那部分** ↦ 关掉后应当是 1.0x / 有声，且视频**不重载**（不回到 0:00）。
- 脚本**不监听站点的倍速变化** ↦ 你在站点自己的播放器菜单里选 1.0x，**不应该被扳回 2.0x**（这是刻意设计的，见 #161）。
- UOOC 的**功能页清单从「空（任意页面）」收紧为「学习页 + 测验页」** ↦ 在课程列表这类页面上，悬浮球还在，但**面板不该自动弹开**。
- 新增一个**只读采样脚本** `tools/dom-probe-uooc-learn.js` ↦ 不影响页面，只是为了 U3 连播取证。
