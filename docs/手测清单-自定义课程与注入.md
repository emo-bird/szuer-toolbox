上一轮（构建号 36）**已回报**：#79–#86 **OK**、#72 OK、#74 OK、#76 OK、#78 OK、#59 OK、#60 OK。
第二轮（构建号 39）**已回报**：探针证明**容器全中（`#myCourseTable` / 7 个 `.cv-col.cv-right` / 21 个站点 `.cv-lesson`）**、**realm 接管已生效**（页面 realm 的 `XMLHttpRequest` 是被我们包过的 `function Wrapped(...)`）、列表冲突追加**已能正常触发**；并报出课表注入的两个 bug —— 本轮修掉。

| 问题 | 真因 | 本轮的处置 | 因此要盯什么 |
|---|---|---|---|
| 【日志】每 300ms 刷一条「课表注入…」 | `MutationObserver` 的回调是**异步**投递的，而写 DOM 是同步的 ⇒ 回调跑的时候同步闸门早已复位，拦不住**自触发**：清掉 → 重注入 → 又触发 | 判据改成「**我们注入的节点还在不在**」（`needsRescan`）：节点还在就什么都不做 | 课表页静置半分钟，注入记录**只应出现一次**（#88） |
| 自定义课程的课名/时间/地点排成**左中右** | 站点结构是「卡片 > div > div{各行}」，**中间那层 div 不是装饰** —— 站点给卡片本身的 CSS 会把直接子元素排成一行，而我们漏了这层 | 补上中间层（`sztb-bkxk-tt-lines`）并显式纵向堆叠 | 应是**上中下**：课名+「自定义」标签 / 时间 / 地点 / 教师（#89） |
| 「关掉自绘后，站点应该自己把自定义课程画出来吧？」 | **待查**：旧仓库文档说规则课表走 `POST elective/teachingTime.do`，但现存的 3 份 HAR 全部来自 `grablessons.do`、**没有一条 `teachingTime.do`**；课表页只返回模板 + 外部 `curriculum.min.js`，数据来源在那份 JS 里 | 见 §3.0 第 3 步：用 Network 面板确认课表页到底请求哪个接口 | 只要告诉我「有没有 `teachingTime` 这条请求」就够了 |

## 1. 前置条件

- 浏览器：Edge（或任一 Chromium），Tampermonkey 已装；卸载旧版后装**构建号 40** 的产物。
- 登录态：已登录 `bkxk.szu.edu.cn`（`http://` 页面）。

- Console 开到 **Verbose**（只会看到启动那几行，这是正常的 —— 业务日志在【日志】标签页）。

### 3.0 环境自检（先做这两步）

| 步 | 动作 | 预期 | 失败时请贴回 |
|---|---|---|---|
| A | 打开课表页，点悬浮窗的**【日志】标签页** | 能看到本轮启动后的日志行（启动信息、迁移/搬运提示等）。若这里也是空的，说明日志没落盘，先贴回来 | 【日志】页全文 |
| B | 同一页按 F12，把 `tools/dom-probe-bkxk-timetable.js` **整段**粘进 Console 回车 | 输出里三条：① 容器命中数（`#myCourseTable`、`.cv-my-course`、`.cv-col.cv-right` 等）与列头文本；② 我们注入的节点在不在；③ **`XMLHttpRequest` / `fetch` 的字符串**：若已生效会显示我们包的 `function Wrapped(...)`，若是原生会显示 `function XMLHttpRequest() { [native code] }` | Console 全文（整段输出原样贴回） |
| C | **同一页**按 F12 → **Network** 面板 → 过滤框输 `do`（或 `teachingTime`）→ 按 F5 刷新课表页 | 告诉我：列表里**有没有 `teachingTime.do` 这条请求**？有的话它的状态码是多少；没有的话**哪几条 `.do` 请求出现了**（`curriculum.do` 是页面本身，不算数据接口） | 把 Network 面板里 `.do` 那几条的**名称 + 状态**截图或抄下来（不要贴请求头/正文） |
