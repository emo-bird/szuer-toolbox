# 手测清单 —— 自定义课程标签页 + 响应接管 + 自绘课表

> **被测对象**：`dist/szuer-toolbox.user.js`（v0.1.0，构建号 **#36**）
> **被测分支**：`feat/bkxk-courses-time`（基于 `feat/bkxk-migration`，含已合并的 `feat/bkxk-list`、`feat/tab-order`）
> **执行方式**：装进 Tampermonkey → 逐条跑 → 逐条打勾
> **回话格式**：全过回「OK」；某条不过回「第 N 条：<现象>」+ Console 报错全文 + 截图
> **时间紧时**：先跑 **#80 / #81 / #83 / #69 / #71** 这五条

## 0. 这一轮改了什么（先读这段，知道该盯什么）

| 改动 | 因此要盯什么 |
|---|---|
| 新增【自定义课程】标签页（站点的**第三个**标签页，排在【设置】前面） | 标签栏里能看到【自定义】；它能**添加**课程（含多段）、**修改**、**启停**、**删除**、**清空** |
| 录入方式从「手写时间串」改成**结构化表单**（周次 / 单双周 / 星期 / 节次 / 地点） | 不再需要记格式；**填错会给出具体哪一项不对**，而不是笼统的「时间未解析」 |
| 表单提交后会拼回「时间地点」文本存储（`place` 仍是唯一真源） | 加完课程后列表里显示「解析出 N 段」；**不该出现**「时间未解析」 |
| 增删改后**立即**重画课表注入 | 在课表页加/改/删/停用课程，卡片**不用刷新**就跟着变 |
| 🟢 `自定义课程` 总开关**真正接上**（此前有开关无行为） | 关掉后【自定义】**整页禁用**，且注入与冲突标记**一起消失** |
| 两个 🟠 开关（`接管课表响应` / `接管列表冲突`）默认关，**每次响应时判** | 不打开就一点都没变；打开后**不用刷新**立即生效；关掉后又变回去 |
| 自绘课表：把自定义课程写进站点课表页的列里 | 课表页多出带「自定义」蓝标签的卡片；撞课的卡片有红框 |
| 响应接管：往列表响应里**追加**冲突描述 | 列表页撞课的教学班**多出**一句「…；自定义课程：课名(地点)」，**站点原有的描述还在** |

> 本轮**不发任何请求、不碰抢课/退选**，所以没有 🔴 风险条目（抢课在批 4，到时候单独一份菜单跑）。

## 1. 前置条件

- 浏览器：Edge（或任一 Chromium），Tampermonkey 已装；卸载旧版后装**构建号 36** 的产物。
- 登录态：已登录 `bkxk.szu.edu.cn`（`http://` 页面，不是 https）。
- 页面：需要有**已选课程**的课表页（`.../curriculum.do`）与**能列出教学班**的选课列表页。
- **从干净状态开始**（推荐）：先在 Tampermonkey 里清掉 `sztb:custom:courses`，
  或直接点【自定义课程】页底部的【清空全部】，再开始跑。
- ⚠️ 两个 🟠 开关默认是**关**的，第 #68 条会把它们打开；跑完记得自己决定是否留着。
- Console 请开到 **Verbose**（本项目的诊断主要是 `console.info`，报错是 `console.error`）。

### 3.2 响应接管 + 自绘课表（#66–#78）

## 4. 通过判据

- 全部条目达预期 ⇒ 回「OK」；
- 部分达预期 ⇒ **逐条**回「第 N 条：达预期 / 第 M 条：<现象>」，不要只回一句「有问题」；
- 任一条**崩溃 / 白屏 / Console 报错** ⇒ 立刻停下，贴 Console 全文，别继续往下跑。
