## 2. 站点适配层接口约定【拟定，待实现时定稿】

```ts
interface SiteAdapter {
  id: string;              // 'bkxk' | 'uooc'
  name: string;            // 显示名
  match: string[];         // 命中哪些 URL（决定该 adapter 是否激活）
  tabs: TabDescriptor[];   // 向悬浮窗注册的标签页
  init(ctx: CoreContext): Promise<void>;
}
```

- adapter **只依赖 core**，站点之间零耦合。
- 跨站点数据一律经 `core/storage`（`GM_setValue`）。
- 所有出网站点请求经 `core/http` 串行队列（硬下限 200ms）。

#### 3.1.1 `uooc防止失去焦点，自动二倍数播放.js`（v1.0.0，1.2 KB）

**已完整读取**。全文只有 23 行，`$(document).ready` + `setInterval(1000ms)`：

```js
var videoButton = document.getElementsByClassName("vjs-big-play-button animated fadeIn")[0];
if (videoButton !== undefined) {
  var video = document.getElementById("player_html5_api");
  video.onended = function () { alert("视频已播放完成"); };
  video.muted = true;
  videoButton.click();
  document.getElementsByTagName("video")[0].playbackRate = 2;
}
```

关键信息：

| 项 | 值 |
|---|---|
| header | `@include */www.uooc.net.cn/*`，`@grant none`，`@version 1.0` |
| 依赖 jQuery 全局 `$` | **是**（页面自带 jQuery） |
| 播放器 | **Video.js**（类名 `vjs-big-play-button` + id `player_html5_api`） |
| 播放手段 | 直接改 `<video>` 原生属性 + 点播放大按钮 |
| 轮询 | `setInterval` 1000ms 反复尝试，无就绪检测 |

> ⚠️ 「防止失去焦点」在这个最小实现里**其实是靠 `muted = true` + 点击播放**间接达成，
> 没有处理 `visibilitychange`。真正的失焦续播机制**待抓包/DOM 验证**。

**答案数据结构**（提炼结果）：

- 内置题库：`source.quiz[]`，每项 `{ question, answer }`，
  其中 `answer` 是**字符串形式的数组**，如 `'["A","C"]'`，原脚本用 `eval()` 解析。
  选项索引经 `ans.charCodeAt() - 'A'.charCodeAt()` 计算 ⇒ **强依赖选项从 A 开始且顺序不变**。
- LLM 答题：约定返回格式 `1. A\n2. B\n3. A,B`（多选逗号分隔，判断题 A=正确 B=错误），
  解析正则 `/^(\d+)\.\s*([A-Z,]+)$/`，失败回退 `/\d+\.[\s]*[A-Z]+/g`。
  调用参数：`temperature: 0.3`，默认模型 `'gpt-3.5-turbo'`。

**其它硬编码常量**：快进/快退 10 秒；音量步进 0.1（0.0–1.0）；倍速默认 2.0；
面板动画 400ms；`setTimeout(start, 250)` 等待视频就绪；答题按钮 loading 3000ms / 失败 2000ms；
`setTimeout(alert, 500)`；依赖 jQuery 未加载时 `setTimeout(init, 500)` 重试。

## 5. 抓包工作流（本项目标准动作）

1. 用户开 mitmweb（`--listen-port 8080 --web-port 8081`），
   Edge 用 ZeroOmega 切到 mitm 情景模式（**只代理目标站点**）。
2. 用户操作目标站点，抓完把 `.flow` 存到 `local/capture/`。
3. 跑 `tools/flow_probe.py` 确认可读 → `tools/flow_index.py` 出请求总表 →
   **与用户确认哪些请求是目标接口**。
4. `tools/flow_slice.py` 分片（每片约 24KB）→ **本地模型**提炼 →
   汇总写进本文（或 `docs/接口清单.md`）。
5. 基于清单写油猴脚本；**主 agent 只读清单，不读原始抓包**。
6. 提醒用户：抓完立刻把 ZeroOmega 切回「直接连接」并停掉 mitmweb。

> ⚠️ `local/capture/` 里的 `.flow` 可能含真实姓名 / 学号 / 手机号，
> **绝不喂云端模型**，只走本地 LM Studio。
