# 开发文档 —— 架构与开发指南

> 现行架构说明。**原按版本记的开发日志已清理**（需要历史可翻 git log）。
> 功能与决策看 `需求文档.md`；5 分钟上手看 `交接文档.md`；依赖图 `architecture.html`。

---

## 1. 项目形态

- **单文件油猴脚本**：源码 TypeScript，`build.mjs` 用 esbuild 打包出
  `dist/szuer-toolbox.user.js`。该产物**提交进 git**（`@updateURL` 指 raw 链接做自动更新）——
  改完源码要 `npm run build` 并把 `dist` 一起提交。
- 头部模板 `src/userscript-header.txt`：`@run-at document-start`、`@grant unsafeWindow`、
  `@noframes`、按站点域 `@match`。
- **零运行时依赖**；`esbuild / typescript / knip` 只在开发期。
- 运行在两个 realm：userscript sandbox 与**页面上下文**（`unsafeWindow`）。跨 realm 的坑见 §7.4。

## 2. 分层与依赖方向（铁律）

```
                     src/main.ts                 ← 入口装配
                          │
        ┌─────────────────┼──────────────────┐
        ▼                 ▼                  ▼
 sites/registry.ts    sites/index.ts     common/ui（悬浮窗/标签页/组件）
 （分派纯函数）        （适配器注册清单）        ▲
        │                 │                  │
        ▼                 ▼                  │
   sites/types.ts ←── 契约中心               │
        │                                    │
        ▼                                    │
 sites/<site>/（uooc / bkxk 适配器）──────────┤
        │                                    │
        ▼                                    ▼
 common/core（http/settings/log/storage/limits） common/ui + common/utils + common/custom
```

- **依赖只向下**：站点层可依赖公共层；**公共层不许 import 站点层**。
- `sites/index.ts` 是适配器的**唯一注册入口**；`tests/suites/sites-registered.test.ts` 用真实
  `registerSites()` 钉住「header 承诺的 @match ↔ 已注册适配器」的一致性（曾因漏注册导致站点静默无反应）。
- `common/core` 是**纯逻辑**（不碰 DOM，可在 Node 直测）；`common/ui` 才碰 DOM。

## 3. 生命周期（`src/main.ts`）

| 时机 | 做什么 |
|---|---|
| document-start 注入 | `registerSites()` 注册适配器 + 把站点声明的开关灌进设置注册表；注入 resolver：`setSiteNameResolver` / `setCurrentSiteResolver` / `setOwnSettingsTabResolver` / `setStatusProvider` |
| 立即 | `resolve(url)` → `{ inject, adapter, autoExpand, reason }`；`adapter.earlyInit({ adapter, url })` —— **必须早于站点脚本**，bkxk 的请求接管就挂在这里 |
| DOM 就绪 | `boot(url, res)`：`createPanel(baseCss, buildEntries(siteTabs), { siteName })`；`adapter.init(...)` 挂站点功能 |
| 之后 | `watchNavigation()`：hashchange / popstate 重新分派；**仅当换了站点适配器**才重建面板 |
| 构建期注入 | `__SZB_VERSION__` / `__SZB_BUILD_TIME__` / `BUILD_NO`（esbuild define） |

> `earlyInit` vs `init` 拆开的唯一理由：**响应接管要抢在站点脚本之前**；DOM 相关的一切等到 `init`。

## 4. 适配器契约（`src/sites/types.ts`）

`SiteAdapter`：

| 字段 | 说明 |
|---|---|
| `id` / `name` | 站点 id（同时是 storage 命名空间前缀）/ 显示名 |
| `hosts` | 主机（精确域或子域规则），`resolve()` 用它命中 |
| `pages` | 功能页 glob（`*` 通配）；命中即 `autoExpand` 展开面板，其余页面只出悬浮球 |
| `tabs` | 站点标签页（`TabRegistration[]`） |
| `toggles` | 站点开关声明（`SiteToggleDef[]`，注册进设置层） |
| `settingsInOwnTabs` | true = 设置拆在站点自己的标签页里，公共设置页不再重复渲染 |
| `earlyInit?(ctx)` | document-start；`SiteEarlyContext = { adapter, url }` |
| `init?(ctx)` | DOM 就绪；`SiteInitContext = { adapter, isFeaturePage, panel }` |

其余契约：`TabRegistration { id, title, order?, css?, mount(root, ctx) }`、`TabContext { siteId, host }`、
`PanelApi`（`collapse/expand/isCollapsed/toast/confirm/alert/alertAuthExpired/activateTab`）、
`RiskLevel`（`safe` 绿 / `trace` 橙 / `irreversible` 红）。

**分派规则（`registry.resolve`）**：命中 `hosts` → `reason:'adapter'`；
否则在 `SUPPORTED_ROOT_DOMAINS`（`szu.edu.cn`）下 → 悬浮球（`reason:'root-domain'`）；
否则不注入。`reason` 只进日志与状态页。

## 5. 公共层模块地图

| 模块 | 职责 |
|---|---|
| `core/http.ts` | **唯一请求出口**：优先级串行队列 + 页面 `fetch`；自己的请求带 `__szuSkip` 让嗅探跳过 |
| `core/settings.ts` | 开关/配置注册 + **风险门禁 `isEnabled`（唯一实现）** + `registeredSiteIds` 等 |
| `core/limits.ts` | 时间参数钳位（唯一下限/上限来源，禁止再写裸数字） |
| `core/log.ts` | 环形缓冲（500 条）+ `scoped(名)` + **读取期**等级过滤 + 订阅 |
| `core/storage.ts` | GM 存储封装 + 命名空间前缀 |
| `ui/panel.ts` | 悬浮窗/悬浮球：拖拽、缩放、折叠、位置大小记忆、按键盾 |
| `ui/panel-geometry.ts` | 悬浮球 ⇄ 面板位置的**纯函数**（无 DOM，可单测） |
| `ui/tabs.ts` / `ui/tab-order.ts` | 标签页容器 / 分组排序纯函数 |
| `ui/tabs/{settings,log,status,login}.ts` | 四个公共标签页 |
| `ui/widgets/*` | `modal` / `confirm` / `toast` / `checkbox` / `settings-form`（配置渲染）/ `auth-alert` |
| `utils/{dom,url,page,clipboard}.ts` | DOM 工具 / URL 匹配（`matchAnyPage` 等）/ 页面判定 / 复制 |
| `custom/courses.ts` | 跨站点的自定义课程模型 |

## 6. 站点层模块地图

### 6.1 UOOC（`uooc.net.cn`，视频课）

- `index.ts` 适配器 + 旧/新版页面判定；`settings.ts` 开关与毫秒配置；`notice.ts` 提示流单一出口。
- `video.ts` 播放器行为（二倍速 / 静音 / 防暂停）；`video-quiz.ts` 视频随机小测自动作答。
- `takeover.ts` + `takeover-utils.ts`：**API 驱动「接管」主循环**（自己发请求取目录，DOM 只读、不点）。
- `fetch-catalog.ts` 取目录/资源（带重试闭环）；`catalog-model.ts` 目录树纯模型（展平 / 拼 hash）；
  `catalog.ts` 监视页「章→节→任务点」视图。
- `intercept.ts` XHR/fetch 嗅探：**交卷响应 `waitCommit` 是唯一有消费者的**；`getCatalogList`/
  `getUnitLearn` 只留痕不缓存。
- `ai/`：`index`（编排）/`runner`（重试）/`llm`（模型 HTTP）/`paper`+`parse`+`prompts`（试卷与提示词）/
  `fill`+`fill-dom`（回填 DOM）/`quiz-ready`（就绪判定）/`overlay`（进度遮罩）/`monitor`（状态）。
- `tabs/`：【视频】【等待】【接管】【监视】【AI 作答】。

### 6.2 bkxk（`bkxk.szu.edu.cn`，抢课）

- `index.ts` 适配器；`settings.ts` 开关/配置；`context.ts`；`page-realm.ts`（`unsafeWindow` 桥）。
- `api.ts` 请求封装；`session.ts` cookie+token 探测；`courses.ts` 教学班模型；`time.ts` 时间文本/周次位图。
- `list.ts` + `list-model.ts` + `list-dom.ts` + `list-style.ts`：选课页注入（教学班 ID / 抢课 / 监控按钮），
  模型与 DOM 读取分层。
- `hijack.ts`：拦截 `teachingTime.do` 把自定义课注入站点渲染；列表冲突追加。
- `timetable.ts` + `timetable-model.ts` + `timetable-style.ts` + `tt-mark.ts`：课表页。
- `tasks.ts` + `tasks-model.ts` 抢课队列引擎；`monitor.ts` + `monitor-model.ts` 余量轮询。
- `custom.ts` + `custom-form.ts` 自定义课程；`legacy.ts` 旧 `localStorage` 一次性迁移。
- `tabs/`：【任务】【监控】【自定义】【设置】。

## 7. 关键约定 / 红线

1. **风险门禁只有一处**（`core/settings.isEnabled`）：🟠/🔴 未显式开启恒 `false`；站点开关 `default` 一律写 `false`。
2. **请求只走 `core/http`**；抢课「写接口总开关」默认关。
3. **站点样式写在 `.ts` 模板字符串里**（`tests/run.ts` 用 Node 原生加载 `.ts`，`import './x.css'` 会
   `ERR_UNKNOWN_FILE_EXTENSION` 打挂整轮测试）。
4. **跨 realm 判元素用鸭子类型**（`nodeType === 1` + `tagName`），**不许 `instanceof`**
   （iframe 有自己的 realm，`instanceof` 恒 false）。
5. 大文件按「**模型 / 视图**」分层：`*-model.ts` 放纯函数、可单测；DOM 层只摆位与事件。
6. 设置项 **id = 存储键，公布后不改**；改语义只改展示名。`GROUP.*` 只作渲染过滤键。
7. 页面判定的路径片段收口到单一来源（如 bkxk 的 `settings.PAGE_MARK`）。
8. 日志用 `scoped('模块名')`；UOOC 提示流单一出口（`notice.ts`）。

## 8. 命令

| 命令 | 作用 |
|---|---|
| `npm run typecheck` | `tsc --noEmit`（覆盖 `src/` 与 `tests/`，严格 + `noUnusedLocals`） |
| `npm test` | 零依赖 harness 的纯函数冒烟（档 1），秒级 |
| `npm run build` | 生成 `dist/szuer-toolbox.user.js` |
| `npm run verify` | 产物自检（头部字段 / 无 ESM 残留 / 适配器已注册 / 标签页齐备 …） |
| `npm run check` | 上面四步串起来（提交前跑它） |
| `npm run graph` | 生成 `docs/architecture.html`（自包含交互依赖图） |
| `npm run knip` | 查未使用文件 / 导出 / 类型 / 依赖（value 导出应为 0） |

## 9. 常见改动怎么做

- **加站点开关**：`sites/<site>/settings.ts` 注册（`TOGGLE`/`VALUE` + `RiskLevel` + `default:false`）→
  在功能处用 `isEnabled(SITE_ID, TOGGLE.X)` 门禁 → 在对应标签页渲染。
- **加标签页**：实现 `TabRegistration`，注册进 `adapter.tabs`（用 `order` 排）。
- **加站点**：实现 `SiteAdapter` → `sites/index.ts` 的 `registerSites()` 注册 →
  `src/userscript-header.txt` 加 `@match` → 在 `sites-registered.test.ts` 加钉子。
- **改 UOOC 播放/接管**：播放器 `video.ts`；接管主循环 `takeover.ts`（配套 `takeover-utils.ts`）。
- **改 bkxk 列表注入**：`list.ts`（模型 `list-model.ts`、DOM 读取 `list-dom.ts`）。
