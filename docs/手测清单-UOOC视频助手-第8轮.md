## 你给的四份采样直接把三个真因钉死了

### 真因 A：旧版的「空白节」根本不是空白，是**被折叠了**

`dom-uooc-blank-section-旧.txt`：

```
节 li 子元素数: 1                      ← 只剩一个标题
  [0] <div> class="basic uncomplete active" 文本=2.2 国防法规（1）
typeof sectionItem.unitSource = object / 长度 4     ← 数据明明有 4 个
sectionItem.hide = true
```

站点自己的资源列表容器写着 `ng-if="!sectionItem.hide && stateParams.sectionId == sectionItem.id"`，
`hide === true` 时**整份资源列表根本不在 DOM 里**。而节标题那个 `ng-click="toggleChapter(sectionItem)"`
就是开合开关 —— 我们点它导航的时候，顺手把它**折起来了**。

→ 现在遇到 `hide === true` 会**点一次标题展开**，而不是当成空节往下跳。

### 真因 B：新版「不断循环打开附件和文档」= 扫描起点丢了

`dom-uooc-blank-section-新.txt`：同样的地址，新版**渲染了 4 个资源项**，`hash` 段只有
`["466490612","63971989","1639840758"]` —— **没有第 4 段（resourceId）**。

新版点开文档 / 附件之后，地址栏就停在这种「只到节」的形态。我原来一见 `hashchange`
就把「上次点开的资源」清掉，于是每轮 `cursor = -1`、从本节头重新扫，那两项又不是
`finished`，就被**反复打开**。

→ 改成：「上次点开的资源」连同**所属章 / 节**一起记，只在章 / 节没变时才认；
hash 里有 resourceId 时以 hash 为准；`hashchange` 不再清它。

### 真因 C：非任务点的文档 / 附件压根不该点开

你那份 diag 里数据层是干净的：

```
278902284 type 10 视频   isTask: true
411525491 type 60 文档   isTask: false   ← finished 永远是 0
1392457488 type 80 测验  isTask: true
0        type 50 附件   isTask: false   ← finished 永远是 0
```

站点不要求完成的项，`finished` 永远不可能是 1 —— 点开也只是白跑一趟。

→ 现在**视频一律点开**（照你「一律看完」的要求），**文档 / 附件只在是任务点时才点开**，
非任务点直接跳过。你问的「新版底层有没有任务点数据」答案是**有**，新旧两版字段同名同义。

### 顺带确认：交卷判据成立

| 采样 | 提交试卷 | 保存试卷 |
| --- | --- | --- |
| `提交通过` | 1 | 1 |
| `提交未通过` | 1 | 1 |
| `已作答` | **0** | **0** |
| `点击确定通过按钮` | **0** | **0** |

交卷成功后「提交试卷」和「保存试卷」**一起**从 DOM 消失（两者都写 `ng-if="vm.paper.can_do…"`）。
判据保留并加强，另外补了一条兜底：**卷子已经渲染出来但两个按钮都没有 → 这是已交过的只读视图**
（否则点到目录里状态过期的测验项时会永远卡在「等交卷」）。

## A. 第 5 条那两个毛病

### #245 ⭐ 不再反复打开文档 / 附件
- 动作：在新版那门课（`466490612`）里跑连播，经过那个含「视频 + 文档 + 测验 + 附件」的节。
- 预期：Console 出现 `跳过非任务点的文档 …` / `跳过非任务点的附件 …`，
  **不会**再反复打开它们；一路往后走到下一节、下一章。
- 失败时贴回：Console 全文。

### #246 ⭐ 折叠的节会自动展开
- 动作：在**旧版**页面上，手点两次目录里的节标题把它折起来（资源列表消失），然后让连播走到那一节。
- 预期：Console 出现 `连播：节 … 是折叠的（hide=true），点开它`，资源列表**重新出现**并继续播。
- 失败时贴回：Console 全文 + 那一节展开前后的截图。

### #247 走到本章最后一节能跨章
- 动作：让连播走到当前章最后一个**有内容**的节之后。
- 预期：`跨章继续` → 自动进下一章；`止于本章` → 停住并打日志。

## B. 测验

### #248 自动打开测验
- 动作：连播走到没做过的测验。
- 预期：测验页自动打开（新标签页），学习页 Console 有 `连播：已替你打开测验 …`。

### #249 ⭐ 交卷后自动关标签页 + 学习页等 5 秒再切
- 动作：在新开的测验页里做题并交卷。
- 预期：测验页提示「正在关闭这个标签页…」并真的关掉；学习页右上角出现
  「测验已完成，5 秒后切下一项」，等满 5 秒后接着播。

### #250 点到「已经交过」的测验不该卡死
- 动作：如果连播点开的测验其实**早就做过了**（目录状态过期）。
- 预期：Console 出现 `判定 这张卷子已经交过（只读视图）`，标签页照样关掉、学习页继续，
  **不会永远卡在「等交卷」**。

### #251 测验没做就该等着
- 动作：连播打开测验后**什么都不做**，等 2 分钟。
- 预期：学习页一直停在测验上，不会自己往后跳。
