# 手测清单 —— bkxk 选课页列表注入（教学班ID / 抢课 / 监控按钮）

> **被测对象**：`dist/szuer-toolbox.user.js`（v0.1.0，构建号 **#25**）
> **被测分支**：`feat/bkxk-list`（基于 `feat/bkxk-migration`）
> **执行方式**：装进 Tampermonkey → 逐条跑 → 逐条打勾
> **回话格式**：全过回「OK」；某条不过回「第 N 条：<现象>」+ Console 报错全文 + 截图
> **时间紧时**：先跑 **7、8、9、12**（点击只入队、按钮切态、重扫不叠块 —— 这四条是这批的核心）
> **与 §8.2 的对应**：本文件第 N 条 = `docs/开发文档.md` §8.2 的第 **N+35** 条（即 1→#36 … 16→#51）

## 0. 这一轮改了什么（先读这段，知道该盯什么）

| 改动 | 因此要盯什么 |
|---|---|
| 每个教学班旁注入一块「教学班ID + 添加抢课 + 添加监控」 | 两种页面形态（卡片 / 列表）都该有；**一张卡里两个教学班要各有一块**，不能都挂到第一个 id 上 |
| 列表类页签改成 flex 并追加一列「抢课模块」 | 表格**不能错位**：每列内容仍在自己的表头下面 |
| 点击按钮只写本地队列，不发请求 | Network 面板**不该有新请求**；按钮要变「已加抢课」/「移除监控」 |
| 站点重绘后靠 MutationObserver 补注入 | 展开/收起卡片、切页签、刷新后**不能出现两块叠在一起** |
| 新增 🟢 开关「列表注入（教学班ID / 抢课按钮）」，默认开 | 关掉后已注入的块要**立即**消失（不用刷新页面） |
| 只改了 bkxk 选课页 | 其他页面（含 bkxk 课程表页、其他站点）**不该有任何蓝框** |

## 1. 前置条件

- 装本分支构建出来的 `dist/szuer-toolbox.user.js`（头部构建号应为 **#25**）。
- 已登录 bkxk，能打开选课页（`…/default/grablessons.do…`）。
- 建议先开 DevTools Console 并切到 Network 面板（第 7~10 条要用）。
- **本项目启动期诊断走 `console.info`**，`console.debug` 会被 Edge 默认过滤 —— 看日志前先确认没开过滤。
- 本轮**不需要**清存储；如果你想测「重复加入」，第 8 条会自己覆盖。

## 3. 用例

### 3.1 卡片类页签（本班课程 / 方案内课程）

| # | 动作 | 预期 | 失败时请贴回 |
|---|---|---|---|
| 1 | 打开选课页，点【本班课程】页签，等列表渲染完 | 每个教学班（教师名那一行）附近出现一块蓝框：第一行 `教学班ID <21 位数字>`（原样、没有千位分隔符或空格），下面两个按钮「添加抢课」「添加监控」 | 整张卡片的截图 + Console 报错全文 |
| 2 | 往下找一门**有两个教学班**的课（例如同一门课下同时有「[39]…」与「[35]…」两块） | 两个教学班**各有一块**，两块里的教学班ID **不相同**，且各自对得上自己的教师 | 同一张卡片的截图（要能看清两个 id） |
| 3 | 点【方案内课程】页签，等列表渲染完 | 与第 1 条相同：每个教学班一块，位置正常 | 截图 + Console 报错全文 |

### 3.3 交互与存储（点击只入队，不出网）

| # | 动作 | 预期 | 失败时请贴回 |
|---|---|---|---|
| 7 | 清空 Network 面板，点某一行的「添加抢课」 | 按钮文字变「已加抢课」并变蓝；悬浮窗弹出成功提示；**Network 面板里没有任何新请求** | Network 面板截图 + Console 报错全文 |

| 11 | 按 F5 刷新页面，等列表重新渲染 | 第 7、9 条点过的教学班，按钮**仍是**「已加抢课」/「移除监控」（说明是从存储读回来的） | 刷新后的截图 |
