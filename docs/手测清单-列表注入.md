## 0. 这一轮改了什么（先读这段，知道该盯什么）

| 改动 | 因此要盯什么 |
|---|---|
| 每个教学班旁注入一块「教学班ID + 添加抢课 + 添加监控」 | 两种页面形态（卡片 / 列表）都该有；**一张卡里两个教学班要各有一块**，不能都挂到第一个 id 上 |
| 列表类页签改成 flex 并追加一列「抢课模块」 | 表格**不能错位**：每列内容仍在自己的表头下面 |
| 点击按钮只写本地队列，不发请求 | Network 面板**不该有新请求**；按钮要变「已加抢课」/「移除监控」 |
| 站点重绘后靠 MutationObserver 补注入 | 展开/收起卡片、切页签、刷新后**不能出现两块叠在一起** |
| 新增 🟢 开关「列表注入（教学班ID / 抢课按钮）」，默认开 | 关掉后已注入的块要**立即**消失（不用刷新页面） |
| 只改了 bkxk 选课页 | 其他页面（含 bkxk 课程表页、其他站点）**不该有任何蓝框** |

## 1. 前置条件

- 装本分支构建出来的 `dist/szuer-toolbox.user.js`（头部构建号应为 **#30**）。
- 已登录 bkxk，能打开选课页（`…/default/grablessons.do…`）。
- 建议先开 DevTools Console 并切到 Network 面板（第 7~10 条要用）。
- **本项目启动期诊断走 `console.info`**，`console.debug` 会被 Edge 默认过滤 —— 看日志前先确认没开过滤。
- 本轮**不需要**清存储；如果你想测「重复加入」，第 8 条会自己覆盖。

### 8.1 结果

| 反馈 | 根因（**真机采样定论**，不是猜的） | 修法（用户拍板 A 方案） |
|---|---|---|
| 卡片内容依旧溢出卡片外 | 站点把 `.cv-course-card` **高度写死 210px**（13 张卡计算高度全是 210px、`overflow: visible`），而卡内 `.cv-info` 实测 **234–254px** ⇒ 内容从卡片下沿漏出。**各卡元素数量本就不同**（有的多一行 `.cv-caption-text` / `.cv-caption-red`），所以「部分溢出部分不溢出」 | 含我们块的卡片改 `height: auto !important; min-height: 210px`（站点原值兜底），卡片按内容长高 |
| 卡片内容行高没有减少 | **不是规则没生效** —— 采样显示紧凑规则命中 13/13、`h5` 的 `margin`/`line-height` 都是我们的值；而是卡片总高由站点那个固定值决定，**不跟内容变**，所以屏幕上看不出差别 | 在动态高度的前提下，同时**缩小卡片内容上下左右边距**：卡片 `padding` 16px → `8px 10px`，卡片内容区上下 margin 统一清零（站点给每个子 div 挂了 `margin-top: 4px`） |

| #61 已选卡占两行 | **站点是 `float:left` 栅格**（`.cv-course-card` 实测 `display:block float:left width≈244 margin:8px`，父容器 `section` 是 `display:block`）⇒ **一行的高度由该行最高的卡决定**。而已选卡比未选卡**正好高 20px**，因为站点给退选按钮**单独开了一整行 div**（该 div 只有它一个子节点；未选课时按钮 `display:none` ⇒ div 塌成 0） | 不压高度（压了也改不了栅格规则），改成**把那个按钮搬走**：退选进 `h5`、「已选」右边；`h5` 由「课名 float + 已选」改成 **flex**（硬约束：h5 宽 216、课名 136 + 已选 41 + 间隙 4 = 177，只剩 35px 而退选要 41px）。星标顺势搬到课名前面 |
| #64 退选「点一次触发多次」 | 🚫 **站点自身缺陷** —— 你做了禁用脚本的对照实验，确认基线同样存在 | **标记，不修复**。本项目只**注入**、不接管退选的点击（我们只改位置、不复制节点，结构上不可能把一次点击变成多次）。⇒ 对批 4 的约束：执行引擎**不得**假设「点一次退选 = 一条请求」 |
