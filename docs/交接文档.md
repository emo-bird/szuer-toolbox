# 交接文档 —— 5 分钟上手

> 这个仓库**没有"待交接的工作"**：代码是当前状态、测试全绿、清理已完成。
> 本文只帮你快速建立心智模型；架构细节看 `开发文档.md`，功能与决策看 `需求文档.md`。

## 一句话

深大校园站点的**单文件油猴脚本**：TypeScript 源码 → esbuild 打包成
`dist/szuer-toolbox.user.js`；一个公共悬浮窗，按域名加载**站点适配器**
（UOOC 视频课 / bkxk 抢课）。

## 必须先知道的 4 件事

1. **`dist/szuer-toolbox.user.js` 是提交进 git 的**（自动更新靠 raw 链接）。
   改完源码要 `npm run build`，并把 `dist` 一起提交。
2. **风险门禁只有一处**：`common/core/settings.ts` 的 `isEnabled`。
   🟠/🔴 开关没显式开启就恒 `false`（站点开关 `default` 一律写 false）。
3. **请求只走 `common/core/http.ts`**（页面 fetch + 串行队列），别自己 `fetch`。
4. **站点 CSS 写在 `.ts` 字符串里**，别 `import './x.css'`（测试用 Node 原生加载 TS，会崩）。

## 架构一张图

```
main.ts（装配：注册站点 → resolve 分派 → 建悬浮窗 → 调 adapter.init）
   │
   ├─ sites/registry.ts   分派纯函数（hosts / pages / 根域悬浮球）
   ├─ sites/index.ts      适配器唯一注册入口
   ├─ sites/types.ts      契约中心
   └─ sites/<site>/       站点适配器
         └─ common/core（http/settings/log/storage/limits）
            common/ui（panel/tabs/widgets）
            common/utils（dom/url/page/clipboard）
            common/custom（courses）
```

**依赖只向下**：站点层能用公共层，公共层**不许**反向 import 站点层。

## 常用命令

| 命令 | 作用 |
|---|---|
| `npm run check` | typecheck + 测试 + build + 产物自检（提交前跑它） |
| `npm test` | 纯函数冒烟，秒级 |
| `npm run graph` | 生成 `docs/architecture.html`（交互依赖图） |
| `npm run knip` | 查未使用文件/导出/依赖 |

## 要改东西时的入口

| 想改 | 去哪 |
|---|---|
| UOOC 播放器行为（倍速/静音/防暂停） | `src/sites/uooc/video.ts` |
| UOOC「接管」连播主循环 | `src/sites/uooc/takeover.ts`（配套 `takeover-utils.ts`） |
| UOOC AI 答题 | `src/sites/uooc/ai/` |
| UOOC 设置/开关 | `src/sites/uooc/settings.ts` + `tabs/` |
| bkxk 选课列表注入 | `src/sites/bkxk/list.ts`（模型 `list-model.ts`） |
| bkxk 抢课 / 监控引擎 | `tasks.ts` + `tasks-model.ts` / `monitor.ts` + `monitor-model.ts` |
| 加一个新站点 | `sites/types.ts` 契约 → `sites/index.ts` 注册 → `userscript-header.txt` 加 `@match` |
