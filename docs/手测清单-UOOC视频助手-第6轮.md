## 附：我这边顺带查到的一件事（**需要你帮个忙**）

你问的「新版的非任务点到底有没有底层数据」——**数据层是有的**：

- 新版资源项的 Angular scope 上那个 `source` 对象，字段跟旧版**逐字相同**，
  里面就带着 `is_task`（还有 `task_id`）。
- 旧版是用 `ng-class="{taskpoint: source.is_task == 1}"` 把这个字段画成界面上那个
  「任务点」小标；新版**没画**，但字段还在。

所以「新版能不能认任务点」我已经把它加进 `__sztbUooc()` 的诊断输出了：

```js
__sztbUooc().resources
// 现在每项长这样：
// { id: '278902284', type: 10, isTask: true/false, taskId: '…', finished: false, videoPos: 193.9 }
```

**麻烦你在新版页面随便挑一个你确定「是任务点」的资源，看一眼那一项的 `isTask` 是不是 `true`**（旧版也看一眼做对照）。结论只影响以后要不要按任务点做区分判断 —— 本轮的行为不依赖它（视频一律播完、文档一律 5 秒），所以**不影响这次验收**。
