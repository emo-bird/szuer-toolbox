# UOOC 抓包作业单 —— 照着做就能解开全部阻塞

> **给谁看**：给**你（项目所有者）**看的操作单，不是给 AI 看的。
> **为什么是你**：UOOC 的一切开发都卡在「需要一次真实抓包」上，而**只有你有账号和登录态**。
> AI 拿到这份抓包后就能开工，拿不到就只能写空壳。
> **预计耗时**：40~60 分钟（四个场景，可以分几次做）。
> **时间紧时**：**只做 [场景 D](#场景-d已完成测验页看答案--最高优先)**，它一个人解开 U6。

---

## 0. 一句话说明

我们要做的是「**替你把已完成的测验里的题目和正确答案拉下来，存成 JSON**」。
做这件事**必须知道站点用了哪个接口、传什么参数、返回什么结构** ——
这东西只存在于浏览器和服务器之间的真实流量里，**只能抓包得到**。

---

## 1. 准备工作（10 分钟，一次就好）

### 1.1 开 mitmweb

在终端里跑（**保持窗口开着**，抓完再关）：

```pwsh
mitmweb --listen-port 8080 --web-port 8081
```

跑起来后浏览器会自动打开 `http://127.0.0.1:8081` —— 这就是抓包面板。

### 1.2 让 Edge 走代理（**只代理 UOOC，别全局代理**）

用 **ZeroOmega**（SwitchyOmega 的继任者）新建一个情景模式：

| 项 | 值 |
|---|---|
| 代理协议 | HTTP |
| 服务器 | `127.0.0.1` |
| 端口 | `8080` |
| 不代理的地址列表 | 保持默认即可 |

再建一条**自动切换规则**（或者在情景模式里直接配）：

```
*.uooc.net.cn  →  mitm
（其它一律「直接连接」）
```

⚠️ **重要**：只让 UOOC 走代理。全局代理会把深大校园网、微信、各种后台流量全抓进来，
既有隐私问题，也会让抓包文件大到没法用。

### 1.3 装 mitmproxy 证书（如果没装过）

1. Edge 里先切到 mitm 情景模式；
2. 访问 `http://mitm.it`，下载 Windows 的证书；
3. 双击安装 → 选「**本地计算机**」→「**将所有的证书都放入下列存储**」→「**受信任的根证书颁发机构**」；
4. **重启 Edge**。

> 如果访问 `http://mitm.it` 打不开，说明代理没生效，先回头检查 1.2。

### 1.4 登录 UOOC

**先在代理关掉的情况下登录好**（或者登录时走代理也行，但登录请求会很多）。
目标状态：**Edge 已登录 `www.uooc.net.cn`，能正常看到你的课程列表。**

## 2. 抓包总则（每次都要做）

1. **开始抓之前，先在 mitmweb 面板里按 `Clear`（清空）** —— 只留这一次场景的流量，别把登录的杂流量混进来。
2. 操作过程中**不要关标签页**。
3. 操作完，在 mitmweb 里 **File → Save → 保存为 `.flow`**，文件名按下面的场景命名，
   **存到 `C:\Project\szuer-toolbox\local\capture\`** 目录。
4. **抓完立刻把 ZeroOmega 切回「直接连接」，并关掉 mitmweb 窗口。**
   （⚠️ 这一步别忘 —— 忘了会让你的日常上网一直走代理。）

**文件名对照表**

| 场景 | 存成 |
|---|---|
| A 旧版学习页 | `uooc-A-旧版学习页.flow` |
| B 新版学习页 | `uooc-B-新版学习页.flow` |
| C 测验做题 | `uooc-C-测验做题.flow` |
| D 已完成测验看答案 | `uooc-D-已完测验看答案.flow` |

## 3. 四个场景

### 场景 A：旧版学习页（解开 V1 / V2' / V6 / V9）

**做什么**

1. 进一门课，停在**旧版**学习页 —— URL 形如
   `https://www.uooc.net.cn/home/learn/index#/…`（路径里**没有** `new`）。
2. **把地址栏整条 URL 复制下来**（等一下要一起回传，V9 靠它）。
3. 点开某一节，**让视频播十几秒**，抓这一段的流量。
4. **切到下一节**（点章节列表里的另一节），再让视频播十几秒。
5. 重复 2~3 次章节切换，然后停。

**要解开什么**

- **V1**：登录态是 cookie 还是 token —— 看请求头里带的是什么；
- **V2'**：暂停的触发点（这条抓包不一定看得出来，看不到就跳过）；
- **V6**：旧版的播放器与类名；
- **V9**：hash 里那三段数字是什么。

**回传时额外告诉我**：地址栏那条完整 URL（尤其 `#/` 后面那三段数字）。

---

### 场景 B：新版学习页（解开 V7 / V8）

**做什么**

1. 找一门课进**新版**学习页 —— URL 形如
   `https://www.uooc.net.cn/home/learn/new/{一串数字}#/…`（路径里**有** `new`）。
2. **把地址栏整条 URL 复制下来。**
3. 同样：点开一节 → 播十几秒 → 切下一节 → 再播十几秒。

**要解开什么**：新版页面的 DOM 与接口是否和旧版一致（**新版零参考，完全从零逆向**）。

> ⚠️ **如果找不到新版页面**（有些账号可能只有旧版），直接回「**没有新版页面**」即可，
> 这本身就是一条重要信息。

---

### 场景 C：测验做题（解开 V4）

**做什么**

1. 找一个**还没做过**的测验（小测验就行，别挑期末考）。
2. 打开它 → **把题目、选项都看一遍**（滚动一下页面）。
3. **随便选几题**（不用全做完）。
4. **提交**。

**要解开什么**：测验页真实的 DOM 结构与接口。

> ⚠️ **这条会真的提交一次答案**，会留痕。**你自己决定要不要做** ——
> 不做也完全可以（场景 D 更重要）。**如果你不愿意提交，直接跳过整个场景 C。**

---

### 场景 D：已完成测验页看答案 —— 🔥 **最高优先**

> **这一个场景单独解开 U6**，也就是「拉取已完成测验的题目与正确答案」。
> 如果时间只够做一个场景，**就做这个**。

**前提**：你得有一个**已经做完的测验**（做完多久都行，历史记录也可以）。

**做什么**

1. 在 mitmweb 面板里按 `Clear` 清空。
2. 进入那个**已完成的测验**页面。
3. **把接下来能点的都点一遍**（这一步要「全都走一遍」，别只点一下）：
   - 把测验**打开**；
   - **滚动看完所有题目**（让题目都渲染出来）；
   - 如果有「**查看答案**」「**查看解析**」「**查看详情**」「**我的作答**」之类的按钮 —— **点它**；
   - 如果有「**再练一次**」「**重做**」—— **先别点**（那会留痕）；
   - 最后**退出这个测验**（返回列表或关闭）。
4. 保存成 `uooc-D-已完测验看答案.flow`。

**要解开什么**

- **V10**（核心）：拉「已完成测验」的**接口路径 / 方法 / 参数 / 响应结构**；
  题干、选项、选项文本、题目类型这四个字段分别落在哪；
- **V11**：一次拿一道题还是整份卷；要不要先取测验 id 列表；
- **V12**：能不能重复请求（会不会留痕）。

**回传时额外告诉我**

- 那个测验在页面上**叫什么名字**（方便我在流量里对上号）；
- 你能看到**题目和正确答案**吗？（能看到的话，说明答案确实下发到了前端，
  这正是我们要抓的东西；**如果看不到答案，也请告诉我** —— 那说明站点不给前端发答案，
  我们的 U6 方案要改。）

## 4. 抓完之后怎么给我

1. 把 4 个（或 1 个）`.flow` 文件放到 `C:\Project\szuer-toolbox\local\capture\`。
2. 回我这几样：
   - **哪些场景做了、哪些跳过了**（跳过没关系，说一声就行）；
   - **场景 A / B 的完整地址栏 URL**；
   - 场景 D 的**测验名字**，以及**你能不能看到答案**；
   - 任何你觉得奇怪的地方（比如「点了查看答案但它转圈不出来」）。
3. 剩下的交给我：我会用 `flow_index` 出请求总表 → 跟你确认哪几个是目标接口 →
   分片提炼 → 写进 `docs/开发文档.md` §3。

## 5. ⚠️ 隐私与风险（必读）

### 隐私

- **`.flow` 文件里会有你的真实姓名、学号、cookie**。所以：
  - 它们只存放在 `local/capture/` —— **这个目录不随 git**，不会被提交、不会上传；
  - 处理时**只走本地模型**（跑在你自己机器上的 LM Studio），**绝不发到云端**；
  - 如果你愿意，可以抓完先自己用 mitmweb 看一眼，把明显不想给我的请求删掉再保存 ——
    但**别删**跟学习页、测验页相关的那些，那正是我要的。

### 风险

- **场景 C 会真的提交一次测验答案**，可能留痕。**要不要做由你决定。**
- **场景 A / B / D 都是只读浏览，不改任何东西**（D 里唯一要注意的是**别点「重做/再练一次」**）。
- 场景 D 里**只点「查看答案/查看解析」，不要点任何带「提交」「重做」「开始答题」字样的按钮**。

### 做完之后

- **把 ZeroOmega 切回「直接连接」**；
- **关掉 mitmweb 窗口**；
- 确认 Edge 能正常上网（如果不正常，多半是代理没切回来）。

## 6. 常见问题

| 现象 | 怎么办 |
|---|---|
| `http://127.0.0.1:8081` 打不开 | mitmweb 没跑起来，或者被别的程序占了 8081 端口 |
| 浏览器访问 UOOC 报「证书错误 / 连接不安全」 | mitmproxy 证书没装好或没装到「受信任的根证书颁发机构」，重做 §1.3 |
| mitmweb 面板里**一条 UOOC 的流量都没有** | ZeroOmega 情景模式没切、或者自动切换规则没匹配上（确认规则写的是 `*.uooc.net.cn`） |
| 抓到的流量里全是别的网站 | 自动切换规则写太宽了，或者全局代理开着 |
| 保存的 `.flow` 特别大（几十 MB） | 多半混进了视频本体的下载。**没关系**，照样给我 —— 我会先出请求总表再分片，不会整份读 |
| 找不到新版学习页 | 直接回「没有」，这也算一条结果 |
| 没有已完成的测验 | 场景 D 做不了。那就先做 A/B/C，并在回传里说明 |
