**现在连播的完整流程**：

```
视频播完 ──┐
打开文档 ──┼─→ 右上角提醒 → 等 N 秒（默认 5，可设）→ 切下一项
测验交卷 ──┘
```

遇到测验时：**自动替你点开**（新版会开新标签页）→ 你在卷子里正常做题交卷 →
测验页自己发现交卷成功 → 写一根跨标签页信号 → 通知学习页 + **把自己关掉** →
学习页收到后提醒 + 等 5 秒 → 接着播下一项。

## A. 测验流程（本轮重点）

### #232 ⭐ 测验会被自动点开
- 动作：连播走到一道**没做过**的测验。
- 预期：**测验页被自动打开**（新版是新标签页），Console 出现
  `连播：已替你打开测验 …，交卷后会自动继续`，学习页右上角有提醒。
- 失败时贴回：Console 全文 + 是否弹了新标签页（浏览器可能拦截，见 #236）。

### #233 ⭐ 交卷后标签页自动关闭
- 动作：在新开的测验页里正常做完并**交卷**。
- 预期：测验页右上角提示「测验已完成，正在关闭这个标签页…」，随后**标签页自己关掉**。
- 失败时贴回：Console 全文 + 是否出现「需要你手动关闭」的提示。

### #234 ⭐ 回到学习页后等 5 秒再切
- 动作：接 #233，看学习页。
- 预期：右上角出现「测验已完成，5 秒后切下一项」，**等满 5 秒**才切。
- 失败时贴回：Console 全文 + 大概等了多久。

### #235 测验没做就不该往下走
- 动作：连播遇到测验后**什么都不做**，等 2 分钟。
- 预期：学习页**一直停在测验上**，不会自己往后跳（除非目录上那一项已经变成完成）。

### #236 弹窗被拦时的表现
- 动作：如果浏览器拦了弹窗（地址栏出现拦截图标）。
- 预期：Console 有日志，学习页不该假装「已经在等你交卷」而永远卡住 —— 请把现象告诉我，
  我会改成「拦下了就提示你手点」。

## B. 空白节（第 5 条）

### #237 ⭐ 空白节会提醒并跳过
- 动作：让连播走到一个**右半边什么都没有**的节。
- 预期：Console 先出现 2–3 次「本节还没看到任何资源（第 N 次），稍后再看」，
  然后右上角提醒「本节没有可看的内容，5 秒后切下一项」，**等 5 秒后跳到下一个节**。
- 失败时贴回：Console 全文 + **请你顺便跑一次下面的采样脚本**。

### #238 有内容的节不被误判
- 动作：让连播经过一个正常有视频 / 文档的节。
- 预期：**不会**出现「本节没有可看的内容」，正常播。

### #239 旧版：做完测验回到学习页能切

## E. 需要你跑的采样（**这轮的关键**）

### #243 ⭐ 空白节 DOM 采样 —— 弄清第 5 条的真实原因
我要判断「这一节真没内容」还是「有内容但我们没看到」，光凭 `resourceItem: 0` 分不出来。

- 文件：`tools/dom-probe-uooc-blank-section.js`
- 动作：
  1. 在 UOOC 学习页**停在那个空白节上**（就是 `__sztbUooc()` 显示 `resourceItem: 0` 的状态）；
  2. F12 → Console → **整段粘贴** → 回车；
  3. 把输出**整段复制**回来（脚本会自己控制长度）。
- 它会告诉我：这一节的 `li` 里有哪些子元素、scope 里 `sectionItem.unitSource` 是数组还是
  undefined（长度多少）、右边那块显示了什么、页面上所有 `ng-repeat` 表达式。

### #244 ⭐ 测验页 DOM 采样 —— 验证「交卷成功」的判据
我现在用的是实测过的判据：`button.btn.btn-danger`「提交试卷」带 `ng-if="vm.paper.can_do"`，
交卷成功后按钮从 DOM 消失。**需要确认它在你这门课上成立。**

- 文件：`tools/dom-probe-uooc-quiz.js`
- 动作：**跑两次**，两次输出都贴回来：
  1. 打开测验、**还没交卷**时跑一次；
  2. **交卷成功之后**再跑一次。
