## 0. 这一批改了什么（先读这段，知道该盯什么）

1. **`@run-at` 从 `document-idle` 改成 `document-start`** —— 脚本现在**在页面任何脚本之前**就跑起来。
   ⇒ 本条最需要盯的是：**有没有把目标站点搞坏**（白屏、报错、页面功能异常）。
2. **请求出口从 GM 通道改成页面 `fetch`**（需求文档 Q-AE）：
   ⇒ `@grant GM_xmlhttpRequest` 与三条 `@connect` 都已删除，新增 `@grant unsafeWindow`。
   ⇒ 副作用：Tampermonkey 的「XHR 跨域」不再由脚本申请，**但本批还没有真实请求发出**，所以暂时看不出来。
3. **200ms 从硬下限降级为软提示**（Q-AF）：
   ⇒ 设置页里把请求间隔填成 50，**应当被接受**（不会弹回 200），只在日志里出现一条 warn。
4. **旧版 bkxk 数据一次性迁移**：
   ⇒ 进一次 `bkxk.szu.edu.cn` 就会把旧脚本的 `localStorage` 数据搬进新存储，并提示你手动再勾危险开关。
5. **【本轮新增】面板 UI 修复**（需求文档 Q-AG / Q-AH）：
   ⇒ **Backspace 能删字了**（修之前被 bkxk 站点的 `banBackSpace` 吞掉，只有 Delete 能用）；
   ⇒ 站点设置**挪进站点自己的标签页**，公共设置页只留一行指引；
   ⇒ 输入框为空时显示灰色默认值，**失焦仍为空就真的填进去**；
   ⇒ 配置项说明**独占一行**；数值非法/低于建议值时**失焦即提示**；
   ⇒ **监控模式 / 监控类别 / 重试策略变成下拉框**。
