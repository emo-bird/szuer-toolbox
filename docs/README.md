## 文档维护约定

- 功能/接口有变，先改 [需求文档.md](需求文档.md) 与 [开发文档.md](开发文档.md)，别只留在 commit message 里。
- 依赖关系变了跑一次 `npm run graph` 重新生成 `architecture.html`。
- 手测清单类文档已删除：可执行校验统一交给 `npm run check`（typecheck + 测试 + 产物自检）。
