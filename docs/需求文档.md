# 需求文档 —— 功能与决策

> 本文件回答「**做什么、为什么这么做**」。怎么写看 `开发文档.md`。
> 原按轮次记录的完整决策流水已清理，这里只留对**改代码有约束力**的内容。

---

## 1. 项目目标

给深圳大学校园站点做一套**一体化油猴脚本**：一个公共悬浮窗 + 按站点加载的适配器，
把上课/选课里重复、耗时的操作自动化。要求：**危险操作必须用户显式确认**、
**限流后果用户自负但要有提示**、**不引入运行时依赖**。

## 2. 目标站点与功能

### 2.1 UOOC 优课联盟（`*.uooc.net.cn`，视频课）

| 功能 | 说明 |
|---|---|
| 视频助手 | 二倍速 / 静音 / **防暂停**（被暂停就恢复，含用户自己按的暂停） |
| 视频随机小测 | 视频播放中弹出的随机测，读 DOM 里的答案自动作答（无开关） |
| **接管（API 驱动连播）** | 一次 `getCatalogList` 拿整棵目录树，自己算下一个任务点、改 `location.hash` 跳转；视频等 `ended`、测验等交卷响应。**DOM 只读不点**；由用户点【开始接管】启动 |
| AI 答题 | 抓取试卷 → 问模型 → 回填 DOM（点选项）/ 交卷；未达标可重答。**默认关**（🟠 不可逆：会交卷） |
| 监视 | 目录树「章→节→任务点」分层列表 + 接管进度 |
| 等待参数 | 接管用的三个时间参数（跳转后等待 / 播完后停留 / 全局等待超时） |

页面判定：旧版 `/home/learn/index#/...`（全套功能）与新路径 `/home/learn/new/...`（提示切旧版）。

### 2.2 本科选课 bkxk（`bkxk.szu.edu.cn`）

| 功能 | 说明 |
|---|---|
| 列表注入 | 选课页每行/卡片注入「教学班 ID」+【添加抢课】【添加监控】按钮（只入队，不发请求） |
| 抢课任务 | 队列引擎按批次码/时间轮次抢课；**写接口总开关默认关**（🔴） |
| 余量监控 | 轮询容量；两种模式：类别监控（拉类别列表，一次一类）/ 单独监控（逐课查，精确） |
| 自定义课程 | 手动录入课程，注入课表页 |
| 课表注入 | 拦截 `teachingTime.do` 响应，把自定义课塞进站点原生渲染（🟠 默认开） |
| 列表冲突追加 | 在站点算好的 `isConflict` 上追加我们算出的冲突（🟠 默认开） |
| 旧数据迁移 | 旧版 `localStorage`（`szubkxk.v2.*`）一次性搬到公共 GM 存储 |

## 3. 设置项清单（改功能前的约束）

> **id = 存储键，公布后不改**；下面只列展示名/风险/默认。id 与分组定义在各站点的 `settings.ts`。

**UOOC 开关**：二倍速（safe，默认开）/ 静音（safe，开）/ 防暂停（safe，开）/ **AI 答题**（irreversible，关）。
**UOOC 配置**：接口地址 / API Key / 模型名 / 超时(ms) / 并发数；等待三参数（5000 / 5000 / 30000）。

**bkxk 开关**：写接口总开关（irreversible，关）/ 课表注入（trace，开）/ 列表冲突追加（trace，开）/
列表注入（safe，开）/ 自定义课程（safe，开）。
**bkxk 配置**：请求间隔(ms) / 抢课重试间隔 / 监控轮询间隔 / 选课批次码 / 监控模式（类别|单独）/ 重试策略（智能|不重试|持续）。

## 4. 关键决策与红线（务必遵守）

1. **风险门禁只有一处实现**（`common/core/settings.ts` 的 `isEnabled`）：🟠/🔴 开关**从未设置过时一律
   `false`**，用户显式勾选后才生效。站点开关的 `default` 也一律写 `false`（写 true 是陷阱）。
2. **请求统一出口**：`common/core/http.ts` 的页面 `fetch`（**不实现 GM_xmlhttpRequest**）——
   bkxk 要求页面 cookie + `token` 头缺一不可，页面 fetch 的报文与站点自身请求逐字节一致。
3. **限流是软约束**：低于建议间隔（200ms）只 `log.warn`，**不改用户输入值**（后果由用户账号承担）。
4. **跨 realm 不许 `instanceof`**：试卷 / 播放器可能在 iframe 里，用鸭子类型判定。
5. **站点样式写在 `.ts`**：测试用 Node 原生加载 TS，`import '.css'` 会崩。
6. **设置 id 即存储键**：改语义只改展示名，改 id 等于丢用户配置（需要迁移才可改）。
7. **脚本必须在 `@run-at document-start` 注入**：bkxk 的响应接管要抢在站点脚本前。

## 5. 明确不做 / 暂不实现

- **U5**：未开始（见 git 历史）。
- 不写死页面位置选择器：题号/行位置这类靠 `input[name]`、`tcid` 等**稳定标识**。
- bkxk 的请求接管只在顶层 realm 装（抢课/课表都在顶层）；UOOC 才有 iframe 补装。

## 6. 建议真机复验（改动相关功能后）

- UOOC 接管：目录取数 → 视频播完 → 测验交卷 → 下一项，整条链路跑通；
  **视频「停在 0:00 不自动播放」**已加兜底（接管里主动 `play()` 一次），可重点看。
- bkxk 抢课：先开【写接口总开关】并二次确认，再跑队列；监控两种模式各跑一轮。
