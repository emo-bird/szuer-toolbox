## B. 自动连播（U3）

> 每条都先**把「自动连播」打开**。连播只在一个视频**播到结尾**时启动。

### #189 ⭐ 基本连播（旧版）
- 动作：旧版学习页，随便挑一个**没看过**的视频，把进度条拖到接近结尾（剩 10 秒左右），等它播完。
- 预期：播完后**自动切到目录里的下一个视频并开始播放**（新视频会自己播起来，不用手点）。
- 失败时贴回：Console 里 `[sztb]` 全部输出 + 该视频的资源 id。

### #190 跳过「已经看过」的视频
- 动作：上面那条播完后，目录里下一个恰好是**你已经看过一部分**的视频（表现为进度条能拖、不是从 0 开始）。
- 预期：不停在它上面，**继续往后跳**，直到找到一个没看过的视频；Console 有「跳过已看过」的日志。
- 失败时贴回：Console 全文 + 那个视频在目录里的 `video_pos`（把鼠标放到目录项上，或在 Console 里 `angular.element(document.querySelector('.active')).scope().source` 看一眼）。

### #191 跳过文档 / 附件
- 动作：让连播路径上经过一个**文档（文本）**或**附件**。
- 预期：直接跳过，不打开、不停留。

### #192 跳过「做过的测验」
- 动作：让连播路径上经过一个**你已经提交过**的测验。
- 预期：直接跳过，继续往后。

### #193 遇到「没做过的测验」停下
- 动作：让连播路径上经过一个**没做过**的测验，且「自动作答」是关的。
- 预期：**停在这个测验上**，Console 打出「连播停在测验 …：没做过的测验不会自动跳过」。
- 失败时贴回：Console 全文。

### #194 本章走完
- 动作：让连播走到**本章最后一个视频**播完。
- 预期（`连播范围 = 止于本章`）：停住，Console 打「已到本章最后一个视频…停在这里」。
- 预期（`连播范围 = 跨章继续`）：**自动打开下一章的第一个视频**并播放。
- 失败时贴回：Console 全文 + 当时的 hash。

### #195 ⭐ 新版学习页连播
- 动作：把 #189–#194 在**新版**学习页（`/home/learn/new/{cid}#/...`）上重跑一遍。
- 预期：行为一致。
- 失败时贴回：Console 全文 + 该页目录里一个资源项的 outerHTML（右键 → 检查 → 复制元素）。

### #196 关掉开关就不跳
- 动作：关掉「自动连播」，再让一个视频播完。
- 预期：**停在那里**，不跳转。

### #197 护栏：不会死循环
- 动作：挑一门**几乎全是文档 / 已看过视频**的课，开连播让它一路跳。
- 预期：最多跳 40 步或 45 秒后放弃，Console 打「连播放弃：…」；**页面不卡死**。

## C. 进度上报（U10）

> 这个开关是 🔴：第一次打开会弹二次确认。抓包看请求用 F12 → Network 过滤 `markVideoLearn`。

### #198 默认关，什么都不发
- 动作：保持「进度上报」关着，播放一个视频 3 分钟。
- 预期：Network 里**没有任何** `markVideoLearn` 请求是脚本发的（**站点自己发的仍在**，注意区分 —— 站点会在暂停等时刻自己发）。

### #199 ⭐ 开启后按随机间隔上报
- 动作：打开「进度上报」（过二次确认），然后**让视频连续播放 5 分钟**，盯 Network。
- 预期：每隔 **30–90 秒**出现一次 `POST /home/learn/markVideoLearn`，body 形如
  `chapter_id=…&cid=…&hidemsg_=true&network=2&resource_id=…&section_id=…&source=1&subsection_id=0&video_length=…&video_pos=…`
  其中 `video_pos` **随播放时间递增**。
- 失败时贴回：Console 全文 + 一条该请求的 Request（Headers / Form Data）+ Response。

### #200 改区间立刻重新计时
- 动作：把 `上报间隔下限` 改成 `5`、`上限` 改成 `10`，保存。
- 预期：**不用等旧的 30–90 秒**，很快就开始按 5–10 秒发。
- 失败时贴回：两次上报的时间戳（Network 里右键该请求 → Copy → Copy all as HAR 里能看到）。

### #201 换集后对着新视频报
- 动作：连播或手动切到**另一个视频**。
- 预期：之后的 `video_pos` 是**新视频**的进度；不会再把旧视频的进度报上去。

### #202 暂停 / 播完时不上报
- 动作：暂停视频，等 3 分钟。
- 预期：脚本**不发** `markVideoLearn`。
